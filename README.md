# 🧩 pinbead-blueprint

**一个 Claude Skill，让 AI 直接帮你把任意图片转成拼豆图纸。**

上传照片，告诉 Claude "帮我做成拼豆图纸"，它会立刻生成一个可交互的图纸工具——颜色已自动匹配到 Mard 221 标准色卡，网格线、坐标轴、珠子用量统计一应俱全，图纸和购买清单都能一键导出。

---

## 效果预览

```
你：帮我把这张猫咪照片做成拼豆图纸，网格用 8px

Claude：[生成交互式图纸工具]
        ├─ 图纸尺寸：52 × 40 格
        ├─ 使用颜色：34 色
        └─ 总珠子数：2,080 颗
```

生成的工具直接在对话窗口内运行，支持：

- 拖拽或点击上传图片
- 调整网格大小，实时重新生成
- 查看每种色号需要多少颗珠子
- 下载图纸 PNG / 导出购买清单 TXT

---

## 功能特性

**图纸生成**
- 自动将图片每个网格区域的平均色匹配到 Mard 221 标准色卡（221 色）
- 颜色匹配算法：RGB 欧几里得距离，找到感知上最接近的色号
- 支持 JPG、PNG、WebP 等常见图片格式

**图纸显示**
- 每格之间有细分隔线，方便数格
- 每 10 格自动加一条粗参考线（横竖各一套）
- 左侧与底部显示坐标轴编号，每 5 格标注一次

**统计面板**
- 图纸总格数（宽 × 高）
- 用到的颜色种数
- 每种 Mard 色号对应多少颗珠子（按用量降序排列，附色块预览）
- 总珠子数

**导出**
- 图纸 PNG：高分辨率，可直接打印或在手机上对照使用
- 购买清单 TXT：包含色号、HEX 值、所需数量，方便采购

### 参数说明

| 参数 | 说明 | 建议值 |
|------|------|--------|
| 网格大小 | 原图每 N 个像素对应图纸上一格；数值越小图纸越精细、格数越多 | 见下表 |
| 显示缩放 | 图纸预览时每格显示多少像素；不影响图纸内容，只影响画面大小 | 默认 12 |

**网格大小参考：**

| 图片类型 | 建议网格大小 | 适合人群 |
|----------|------------|----------|
| 简单图标 / Logo | 4–8 px | 初学者，珠子数少 |
| 人像 / 风景照 | 8–16 px | 中级，效果平衡 |
| 需要高精度细节 | 2–4 px | 进阶，格数多 |

## 色卡说明

本 Skill 使用 **Mard 221 标准色卡**，共 221 种颜色，色号格式为字母+数字组合（如 `A1`、`B12`、`H7`），与 Mard 品牌拼豆的实物色号直接对应，可凭色号在拼豆店购买对应颜色。

色卡完整数据见 [`assets/Mard221.csv`](assets/Mard221.csv)，包含每种颜色的 HEX 值与色号。

## 工作原理

```
用户上传图片
    ↓
按网格大小切块（默认每块 8×8 像素）
    ↓
计算每块的平均 RGB 值
    ↓
在 Mard 221 色卡中寻找 RGB 欧几里得距离最近的色号
    ↓
用匹配到的颜色渲染图纸 Canvas
    ↓
叠加网格线、10格粗线、坐标轴编号
    ↓
统计各色号用量，显示在图纸下方
```

核心颜色匹配：

```js
// 欧几里得距离寻找最近色
function nearestColor(r, g, b) {
  let best = null, bestD = Infinity;
  for (const p of palette) {
    const d = (r - p.r)**2 + (g - p.g)**2 + (b - p.b)**2;
    if (d < bestD) { bestD = d; best = p; }
  }
  return best;
}
```

## 常见问题

**Q：生成的图纸颜色感觉不够准确？**  
A：尝试调小网格大小，让每格包含更少像素，颜色平均会更精确。也可以适当提高原图对比度再上传。

**Q：图纸格数太多，太复杂了怎么办？**  
A：增大网格大小（比如从 8 调到 16），格数会大幅减少，颜色种数也会降低，更适合初学者。

**Q：我用的不是 Mard 品牌的珠子，色号能对上吗？**  
A：目前只支持 Mard 221 色卡。导出清单里有每种颜色的 HEX 值，可以拿去和其他品牌的色卡比对。

**Q：能支持其他品牌的色卡吗？**  
A：欢迎提 Issue 或 PR，替换 `assets/Mard221.csv` 并保持 `HEX,Tag` 格式即可适配其他色卡。
